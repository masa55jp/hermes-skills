# エディタと書き出し版で変わるところ

LLMが自力で導けない種類の知識。**書き出す前にこの一覧を通す。**

各項目に「確認済み」と書いてあるものは、Godot 4.7.2 で実際に測って確かめたもの。
それ以外は仕様として広く知られているが、疑うなら自分の環境で測り直すこと。

## 1. インポート対象のファイルは、元の名前で一覧できない ★確認済み

`.png` `.jpg` `.ogg` `.wav` `.ttf` などインポータを通るファイルは、書き出すと
元ファイルがフォルダから消え、`.import` だけが残る。実体は `.godot/imported/` 側へ移る。

```
DirAccess.get_files_at("res://assets/worker/idle")
  エディタ    → ["frame_000001.png", "frame_000001.png.import", ...]  32件
  書き出し版  → ["frame_000001.png.import", ...]                      16件
```

**影響**: 拡張子で絞る一覧処理が全滅する。例外は出ない。
**対処**: 一覧せず、明示パスで `load()` する。枚数は引数で渡す。

```gdscript
load("res://assets/worker/idle/frame_000001.png")   # 両方で動く
```

## 2. `@tool` / `EditorPlugin` は書き出し版で動かない

エディタ拡張は書き出し版では実行されない。ファイルは pack に含まれうるが、
中身が走ることはない。

**影響**: エディタで動いていた前処理が、書き出し版だけ効かない。
**対処**: 実行時に必要な処理を `@tool` スクリプトに置かない。
⚠ **除外するときは慎重に。** autoload がその中のクラスを辿っていると起動しなくなる。

## 3. デバッグ判定が反転する ★確認済み

| | エディタ / debug書き出し | release書き出し |
|---|---|---|
| `EngineDebugger.is_active()` | true | **false** |
| `OS.is_debug_build()` | true | **false** |

**影響**: デバッグ時だけ動く初期化に本番の処理を混ぜていると、release で消える。
逆に、この判定でガードしてあるアドオンは release では無害になる
（godot-mcp の game_bridge がこの形）。

## 4. 書き出し先が pack の中に入る ★確認済み

`export_filter="all_resources"` のまま、書き出し先をプロジェクト内
（`build/web/index.html` など）に置くと、**前回の出力が次回の pack に取り込まれる。**

**影響**: 書き出すたびに肥大する。アイコンPNGなどが二重に入る。
**対処**: `exclude_filter="build/*"`。

## 5. `res://` は書き込めない

書き出し版の `res://` は pack の中で読み取り専用。エディタでは実フォルダなので書ける。

**影響**: セーブデータや生成ファイルを `res://` に書く処理が、書き出し版だけ失敗する。
**対処**: `user://` を使う。

## 6. スクリプトの見え方が変わる

`script_export_mode` によって `.gd` が `.gdc`（バイナリトークン）になる。
`.gd` という名前でフォルダを一覧しても見つからないことがある。

**影響**: スクリプトを動的に列挙する処理が空振りする。
**対処**: 列挙しない。必要なら明示的に `preload` して配列に持つ。

## 7. Web固有

- **スレッド**: `variant/thread_support` が false だと `Thread` が使えない。
  有効にすると配信側に `Cross-Origin-Opener-Policy` / `Cross-Origin-Embedder-Policy`
  ヘッダが必要になる。ヘッダが無いと起動しない
- **音**: ブラウザはユーザー操作の前に音を鳴らさない。無音に見えるのは仕様
- **判定**: `OS.has_feature("web")` で分岐できる
- **ファイル**: ローカルの絶対パスは触れない

## 8. 見落としの構造

このバグ群に共通するのは、**エラーが出ないこと**。

- 例外が飛ばない
- 起動テストが通る
- ログが空

だから「動かして確かめた」では捕まらない。**書き出した pack に対して、
ゲームと同じ呼び出しを再現して測る**しかない。`scripts/verify_export.py` がそれをやる。
