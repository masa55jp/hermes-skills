# 書き出したGodotを検査する

## いつ使うか

- **書き出したとき。** 毎回。`--export-release` の直後に必ず1回通す
- **「エディタでは動くのにブラウザ版だけおかしい」とき**
- 画像・音・シーンが**エラーも出さずに消える**とき

## いちばん大事なこと

**エディタと書き出し版は、別のファイルシステムになる。**

エディタで見ているのはプロジェクトのフォルダ。書き出し版が見ているのは pack の中身。
この2つは中身が違う。とくに **`.png` などのインポート対象は、元のファイルが
フォルダから消え、`.import` だけが残る。**

```
エディタ            frame_000001.png     frame_000001.png.import
書き出し版                               frame_000001.png.import
```

だから拡張子で絞ってフレームを集めるコードは、**エディタで16枚・書き出し版で0枚**になる。

```gdscript
for f in DirAccess.get_files_at(dir):
    if f.ends_with(".png"):      # 書き出し版では1件も一致しない
        frames.add_frame(anim, load(dir + "/" + f))
```

★ **例外は出ない。警告も出ない。空のアニメーションができて、画面から消えるだけ。**
起動テストも通ってしまう。だから「動かして確かめた」では捕まらない。

一方、**明示パスで読むのは両方で動く。** テクスチャ自体は pack の中にある。

```gdscript
for i in max_frames:
    var tex: Texture2D = load("%s/frame_%06d.png" % [dir, i + 1])
    if tex == null:
        break
    frames.add_frame(anim, tex)
```

フォルダを一覧しないので、書き出し版でも同じ結果になる。**枚数を引数で渡す**のが要点。

## 検査を走らせる

```bash
python3 scripts/verify_export.py <プロジェクトのパス> --preset Web
```

やっていること。**書き出した pack を実際に読み込み、ゲームと同じ呼び出しを再現する。**
推測ではなく実測なので、通れば本当に通っている。

| 通過条件 | 落ちるとどうなるか |
|---|---|
| 書き出した pack が読める | そもそも壊れている |
| **実行時に走査するフォルダが空でない** | ★上記のバグ。絵が無言で消える |
| 書き出し先が pack の中に入っていない | 書き出すたび前回の出力を飲み込み、肥大する |
| pack 単体で起動してエラー0件 | autoload やシーンの読み込みに失敗している |

終了コードは 全通過=0 / 未通過=1 / 検査不能=2。**ビルド手順に挟んで、1なら止める。**

`--json` で機械可読な出力になる。`--boot-seconds N` で起動テストの秒数を変えられる。

## 落ちたときにやること

**「実行時に走査するフォルダが空でない」が落ちたら**、そのフォルダを一覧している
コードを探し、**明示パス方式に書き換える**。枚数はハードコードでよい。
`load()` が `null` を返したら止める形にすれば、枚数がずれても落ちない。

**「書き出し先が pack の中に入っている」が落ちたら**、`export_presets.cfg` の
`exclude_filter` に書き出し先を足す。

```
exclude_filter="build/*"
```

**「起動してエラー0件」が落ちたら**、出ているエラーをそのまま読む。
autoload のパス、除外しすぎたアドオン、シーンの依存あたりが原因になりやすい。

⚠ **エディタ専用スクリプト（`@tool` / `EditorPlugin`）の除外は慎重に。**
検査は助言として件数を出すが、通過条件にはしていない。autoload がその中の
クラスを辿っていることがあり、**除外すると起動しなくなる。**
除外したら必ずもう一度検査を通す。

## 検査そのものを疑うとき

**一度も落ちるところを見ていない検査は信用できない。**

```bash
bash scripts/selftest.sh
```

わざとバグのある最小プロジェクトを作って書き出し、検査が終了コード1で
落ちることを確かめる。落ちなければ検査側が壊れている。

## 終わり方

**未通過があるものを「書き出し完了」と呼ばない。** どこが未通過かを明示して人間に渡す。
直したら、必ずもう一度書き出して、もう一度検査を通す。
